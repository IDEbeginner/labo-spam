# Labo SPAM

Simulateur de decks pour SPAM (jeu de cartes de Ticroco), construit sur ma collection.

- **Tester un deck** : 4 cartes, talents, Multiplicateur → partie simulée tour par tour.
- **Chercher le meilleur deck** : évalue toutes les combinaisons de 4 cartes (~3,9 millions).
- **Cartes** : chaque carte est modifiable.
- **Règles et infos** : les règles encore inconnues sont testées dans les deux sens tant qu'elles ne sont pas confirmées.

Données : metabot.gg (v1.20) corrigées avec les patchs 1.21 → 1.26. C'est un modèle de partie, pas le moteur du jeu.
Sur ce site, tes réglages sont enregistrés dans ton navigateur uniquement.

Site fan, non affilié à Ticroco.
